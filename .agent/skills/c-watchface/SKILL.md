# C Watchface (Native SDK)

C is the native SDK path (`"projectType"` absent, code in `src/c/main.c`). Unlike Alloy it runs on **every** Pebble platform.

Everything here is verified against pebble tool v5.0.40 / SDK 4.33.1 (emery, gabbro and aplite emulators).

## Fast path — complete watchface from the verified template

```bash
SKILL=<this skill dir>
cp -R "$SKILL/templates/watchface" my-face && cd my-face
uuidgen                       # paste into package.json → pebble.uuid
python3 "$SKILL/scripts/fetch_font.py" .   # resources/fonts/Jersey10-Regular.ttf (sha256-checked, OFL — not committed)
pebble build                  # builds all 7 platforms
pebble install --emulator emery
pebble screenshot --no-open --emulator emery shot.png   # then READ the image
```

Only the font is fetched: `resources/images/bt-icon.png` is generated by `scripts/make_bt_icon.py` and committed, so the template carries no third-party binaries.

The template is the tutorial's end state: time + date in a custom Jersey font, battery bar, Bluetooth icon + vibration, Open-Meteo weather via PebbleKit JS, Quick View layout shifts, and Clay settings persisted on the watch.

## Project anatomy

```
project/
├── package.json                 # watchapp.watchface, targetPlatforms, capabilities, messageKeys, resources.media
├── wscript                      # stock Pebble wscript — never edit
├── src/
│   ├── c/main.c                 # ALL watch-side code
│   └── pkjs/
│       ├── index.js             # phone side: HTTP + geolocation + Clay
│       └── config.js            # Clay config schema (settings UI)
└── resources/
    ├── fonts/Jersey10-Regular.ttf
    └── images/bt-icon.png
```

**All resource files must live under `resources/`**, and every one must have an entry in `package.json → pebble.resources.media`. The `name` field becomes `RESOURCE_ID_<name>` in C.

Scaffold alternative: `pebble new-project --simple <name>` (empty project), then set `"watchapp": {"watchface": true}`.

## Build / test loop

| Goal | Command |
|---|---|
| Build (all platforms in `targetPlatforms`) | `pebble build` → `build/<name>.pbw` |
| Install on a platform | `pebble install --emulator emery` (also `aplite`, `basalt`, `chalk`, `diorite`, `flint`, `gabbro`) |
| Screenshot (**read the PNG afterwards**) | `pebble screenshot --no-open --emulator emery shot.png` |
| Logs (`APP_LOG`, pkjs `console.log`) | `pebble logs --emulator emery` — **may stay empty; never treat an empty log as failure** |
| Battery state | `pebble emu-battery --percent 15 --emulator emery` |
| Disconnect / reconnect | `pebble emu-bt-connection --connected no --emulator emery` |
| Timeline Quick View | `pebble emu-set-timeline-quick-view on --emulator emery` |
| Clock / format | `pebble emu-set-time ...`, `pebble emu-time-format --format 12h` |
| Settings page | `pebble emu-app-config --emulator emery` (opens a browser; headless alternative in [reference/06-settings.md](reference/06-settings.md)) |
| Restart a wedged emulator | `pebble kill` then reinstall (a fresh emulator boots clean); `pebble wipe` **prompts interactively** |

Notes that cost time if unknown:

- **`emu-bt-connection` / `emu-set-timeline-quick-view` can take a few seconds and sometimes need re-issuing.** If a screenshot shows no change, send the command again and re-shoot before suspecting the code.
- **Installing sends the app to the launcher, not always to the foreground.** If the screenshot shows the launcher or an old app, the previous app may also be stuck ("X is not responding") — `pebble kill` and reinstall.
- Never judge state from a stale screenshot: check the clock advanced, or change the battery and confirm the bar redraws.

## Core patterns

### App skeleton

```c
#include <pebble.h>

static Window *s_main_window;

static void main_window_load(Window *window) { /* create layers */ }
static void main_window_unload(Window *window) { /* destroy layers, unload fonts */ }

static void init() {
  s_main_window = window_create();
  window_set_background_color(s_main_window, GColorBlack);
  window_set_window_handlers(s_main_window, (WindowHandlers) {
    .load = main_window_load, .unload = main_window_unload
  });
  window_stack_push(s_main_window, true);
  tick_timer_service_subscribe(MINUTE_UNIT, tick_handler);
}

static void deinit() { window_destroy(s_main_window); }

int main(void) { init(); app_event_loop(); deinit(); }
```

Every `*_create()` needs a matching `*_destroy()`; `fonts_load_custom_font()` needs `fonts_unload_custom_font()`.

### Time and date

```c
static void update_time() {
  time_t temp = time(NULL);
  struct tm *tick_time = localtime(&temp);

  static char s_time_buffer[8];                    // static: the layer keeps the pointer
  strftime(s_time_buffer, sizeof(s_time_buffer),
           clock_is_24h_style() ? "%H:%M" : "%I:%M", tick_time);
  text_layer_set_text(s_time_layer, s_time_buffer);

  static char s_date_buffer[16];
  strftime(s_date_buffer, sizeof(s_date_buffer), "%a %b %d", tick_time);
  text_layer_set_text(s_date_layer, s_date_buffer);
}

tick_timer_service_subscribe(MINUTE_UNIT, tick_handler);   // never SECOND_UNIT by default
```

### Platform branching

```c
GRect bounds = layer_get_bounds(window_get_root_layer(window));
int y = PBL_IF_ROUND_ELSE(bounds.size.h / 8, bounds.size.h / 28);   // round vs rect
GColor c = PBL_IF_COLOR_ELSE(GColorGreen, GColorWhite);             // color vs aplite/diorite
```

### AppMessage (watch ↔ phone)

```c
// Register BEFORE opening, or early messages are dropped
app_message_register_inbox_received(inbox_received_callback);
app_message_register_inbox_dropped(inbox_dropped_callback);
app_message_register_outbox_failed(outbox_failed_callback);
app_message_register_outbox_sent(outbox_sent_callback);
app_message_open(256, 256);        // 256+ once Clay settings share the channel

// Send a request
DictionaryIterator *iter;
if (app_message_outbox_begin(&iter) == APP_MSG_OK) {
  dict_write_uint8(iter, MESSAGE_KEY_REQUEST_WEATHER, 1);
  app_message_outbox_send();
}

// Receive: numbers arrive as int32, strings as cstring
Tuple *t = dict_find(iterator, MESSAGE_KEY_TEMPERATURE);
if (t) { int temp = (int)t->value->int32; }
```

Keys declared in `package.json → pebble.messageKeys` become `MESSAGE_KEY_<name>` in C and are addressable by name in pkjs.

### Persisted settings

```c
typedef struct ClaySettings { GColor BackgroundColor; GColor TextColor; bool TemperatureUnit; bool ShowDate; } ClaySettings;
static ClaySettings settings;

static void prv_load_settings() {
  prv_default_settings();                                              // defaults first…
  persist_read_data(SETTINGS_KEY, &settings, sizeof(settings));        // …then overwrite
}
static void prv_save_settings() { persist_write_data(SETTINGS_KEY, &settings, sizeof(settings)); }
```

Defaults first means new struct fields always have a value, even with older saved blobs.

## Pitfalls

| Symptom | Cause / fix |
|---|---|
| Nothing on screen at launch | Layers not added to the window's root layer, or text layer never given text; a watchface shows a black screen when only the window is created. |
| App frozen / "not responding" dialog in the emulator | Crashed or wedged instance — `pebble kill` and reinstall. Also seen when a *previous* app on the emulator hung; do not debug your code from that screenshot. |
| Garbled or empty text | `text_layer_set_text()` with a non-static buffer that has gone out of scope — use `static char` buffers. |
| Custom font missing at runtime | Font not declared in `package.json → resources.media`, file not under `resources/`, or `name` mismatch with `RESOURCE_ID_*`. Font resources need `"compatibility": "2.7"`. |
| Crash on exit / unload | Destroying a layer before unloading the font it uses, or services still calling into destroyed layers — unsubscribe and destroy in the right order. |
| Battery/BT/tick callbacks after unload | `tick_timer_service_unsubscribe()`, `battery_state_service_unsubscribe()`, `connection_service_unsubscribe()`, `unobstructed_area_service_unsubscribe()` in the unload handler. |
| Messages never arrive on the watch | `app_message_register_*` called after `app_message_open()`, or the key is not in `messageKeys`. |
| Clay messages dropped | Inbox/outbox too small for the settings dictionary — use 256 (or more). |
| Bitmap invisible | Missing `bitmap_layer_set_compositing_mode(layer, GCompOpSet)` for transparent icons, or a resource id typo. |
| Layout breaks with a notification | Position with `layer_get_unobstructed_bounds()`; clear/cover with `layer_get_bounds()` semantics and read [reference/05-timeline-quick-view.md](reference/05-timeline-quick-view.md). |
| Weather stuck on "Loading..." | pkjs never got a fix: check `capabilities: ["location"]`, that `PEBBLE_` geolocation is permitted, and that the key names match on both sides. |

## Delivery checklist

- [ ] `package.json`: `watchapp.watchface: true`, unique UUID, `targetPlatforms`, `capabilities`, `messageKeys`, `resources.media`
- [ ] `src/c/main.c` with `init()`/`deinit()`/`main()`, load/unload handlers, all `*_create` matched with `*_destroy`
- [ ] `MINUTE_UNIT` tick subscription (unless seconds were explicitly requested)
- [ ] `pebble build` clean for every target platform
- [ ] Installed on emery, screenshot read and visually verified (no clipping, centered, features visible)
- [ ] Round (gabbro/chalk) and monochrome (aplite/diorite) sanity-checked when claimed
- [ ] Battery / BT / Quick View / settings paths exercised with the `emu-*` commands when implemented
