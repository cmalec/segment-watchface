# Part 3 — Battery Meter and Bluetooth Alerts

**Goal:** color-coded battery bar at the top, Bluetooth icon + vibration when the phone disconnects.

## Battery

```c
static Layer *s_battery_layer;
static int s_battery_level;

static void battery_callback(BatteryChargeState state) {
  s_battery_level = state.charge_percent;
  layer_mark_dirty(s_battery_layer);           // redraw the bar next frame
}

// in init(), after window_stack_push() so the layer exists:
battery_state_service_subscribe(battery_callback);
battery_callback(battery_state_service_peek());   // immediate value for the first draw
```

## The bar (Layer + LayerUpdateProc)

A plain `Layer` with an update proc gives full control:

```c
static void battery_update_proc(Layer *layer, GContext *ctx) {
  GRect bounds = layer_get_bounds(layer);
  int bar_width = (s_battery_level * (bounds.size.w - 4)) / 100;   // inside the border

  graphics_context_set_stroke_color(ctx, GColorWhite);
  graphics_draw_round_rect(ctx, bounds, 2);

  GColor bar_color;
  if (s_battery_level <= 20) {
    bar_color = PBL_IF_COLOR_ELSE(GColorRed, GColorWhite);
  } else if (s_battery_level <= 40) {
    bar_color = PBL_IF_COLOR_ELSE(GColorChromeYellow, GColorWhite);
  } else {
    bar_color = PBL_IF_COLOR_ELSE(GColorGreen, GColorWhite);
  }

  graphics_context_set_fill_color(ctx, bar_color);
  graphics_fill_rect(ctx, GRect(2, 2, bar_width, bounds.size.h - 4), 1, GCornerNone);
}
```

```c
int bar_width = bounds.size.w / 2;
int bar_x = (bounds.size.w - bar_width) / 2;
int bar_y = PBL_IF_ROUND_ELSE(bounds.size.h / 8, bounds.size.h / 28);
s_battery_layer = layer_create(GRect(bar_x, bar_y, bar_width, 8));
layer_set_update_proc(s_battery_layer, battery_update_proc);
layer_add_child(window_layer, s_battery_layer);
```

On monochrome platforms (aplite, diorite) the `PBL_IF_COLOR_ELSE` fallback is white — the bar still shows level from its fill width (verified on aplite: a white fill that shrinks).

## Bluetooth

```c
static BitmapLayer *s_bt_icon_layer;
static GBitmap *s_bt_icon_bitmap;

static void bluetooth_callback(bool connected) {
  layer_set_hidden(bitmap_layer_get_layer(s_bt_icon_layer), connected);   // hidden while connected
  if (!connected) {
    vibes_double_pulse();
  }
}

// in init():
connection_service_subscribe((ConnectionHandlers) {
  .pebble_app_connection_handler = bluetooth_callback
});
```

Bitmap resource (`package.json`):

```json
{ "type": "bitmap", "name": "IMAGE_BT_ICON", "file": "images/bt-icon.png" }
```

```c
s_bt_icon_bitmap = gbitmap_create_with_resource(RESOURCE_ID_IMAGE_BT_ICON);
s_bt_icon_layer = bitmap_layer_create(GRect((bounds.size.w - 30) / 2, bar_y + 12, 30, 30));
bitmap_layer_set_bitmap(s_bt_icon_layer, s_bt_icon_bitmap);
bitmap_layer_set_compositing_mode(s_bt_icon_layer, GCompOpSet);   // required for transparent PNGs
layer_add_child(window_layer, bitmap_layer_get_layer(s_bt_icon_layer));
```

The template's icon is generated by `scripts/make_bt_icon.py` (30x30, white rune, transparent background) so no third-party asset is needed.

For icons and animation that should scale or be manipulated point-by-point, use a PDC vector asset instead of a bitmap layer — see the `vector-animations` skill (`gdraw_command_image_draw`, sequences, runtime recolouring).

Initial state comes from the unobstructed handlers in part 5 (`connection_service_peek_pebble_app_connection()`); call that yourself if you are not doing part 5.

## Verify

```bash
pebble build && pebble install --emulator emery
pebble emu-battery --percent 80 --emulator emery   # green
pebble emu-battery --percent 30 --emulator emery   # yellow
pebble emu-battery --percent 10 --emulator emery   # red
pebble emu-bt-connection --connected no --emulator emery    # icon appears (+vibration on device)
pebble emu-bt-connection --connected yes --emulator emery
```

Screenshot after each change and read the image. **The BT toggle can take a few seconds and sometimes needs re-issuing** — if the icon does not appear, send it again before debugging code.

## Gotchas

- `layer_mark_dirty(layer)` is what schedules the redraw; setting `s_battery_level` alone changes nothing.
- Call `battery_callback(battery_state_service_peek())` after subscribing, or the bar starts empty.
- Unsubscribe services in the unload handler before destroying the layers they touch.
- Bitmaps with transparency need `GCompOpSet`; without it the icon's background paints over the face.
